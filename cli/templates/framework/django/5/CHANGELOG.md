# Changelog — Django 5 template set

## [0.1.0] — initial

- 4 skills authored : standards, orm-patterns, tests-pytest-django,
  rest-framework.
- Targets Django 5.x + Python 3.12+.
- PostgreSQL-flavoured ORM patterns (use most idioms work on other
  RDBMS too).
