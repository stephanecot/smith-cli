# Changelog — Python 3 template set

All notable changes to this language template set are recorded here.

## [0.1.0] — initial

- 5 skills authored : standards, tests-coverage, typing, packaging,
  linting.
- Targets Python 3.12+ with src/ layout + PEP 621 `pyproject.toml`.
- Toolchain : ruff (lint + format), mypy (typing), pytest (tests),
  uv (dependency management + venv).
