name: npm
description: Run an npm command (install, run <script>, test, build, lint, ci, audit) inside the project's frontend workspace, in a dedicated sub-agent — keeps multi-thousand-line Vitest / Vite / lint logs out of the parent context. Trigger with `/npm <args>` (e.g. `/npm test`, `/npm run build`, `/npm ci`, `/npm run lint`).
