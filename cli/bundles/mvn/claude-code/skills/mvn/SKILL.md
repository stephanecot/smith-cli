---
name: mvn
description: Run a Maven command (mvn) on the project's reactor in a dedicated sub-agent — keeps multi-thousand-line build logs out of the parent context. Trigger with `/mvn <goals>` (e.g. `/mvn verify`, `/mvn -pl <module> test`, `/mvn dependency:tree`).
